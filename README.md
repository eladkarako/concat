<h3><img width="48" src="resources/app.png" /> concat</h3>this little tool started about 5 months ago (..from September 18 2016), it took me 3 days (one of my first Rust programs), I just needed accurate `concat` Windows and Linux, and didn't want to use Windows `copy` in binary mode,  and didn't want to compile GNU tools with their dependencies to multiple architectures. needed something consistent.  I also needed few "middle" handling like cleaning/trimming stuff, which resulted with additional few programs to do that (mostly designed to be used as a part of pipeline).this was very silly but good dive into Rust.  it is a good learning experience to program something you really need to use.  now days the best practice is the code fast,  so most of the project are A.I. generated.  but you must know the language in-order to debug  as well as navigate the agent to generate stuff you know are written wrong,  or at least it is more useful.this code, was built with 3 minutes.  using a modified Claude Haiku 4.5 agent.  but it took a lot of fiddling to clean-up the result and join some segments,  the most important optimizations are working in bytes,  streaming the content (and when needed, multi-threading).  as well as reducing the CPU/RAM and result size (so minimum dependencies),  this build also includes few more linux targets such as PowerPC,  as well as Android (and Windows), both "normal" and with various ARM CPUs.  <hr/><hr/>see `--help` for information about the actual program.  ```txtUsage:  concat.exe [OPTIONS] will run the commands below to build all the releases,  this is very specific to my machine. you'll need to install C++ development using visual-studio community setup,  for Android you'll need Android Studio and SDK and NDK (and adjust the paths in `.cargo/config.toml`),  for linux there is a custom toolchain I downloaded since `apt` didn't had it, and toolchains and some dependencies needs to be installed on WSL.  eventually this script will build Windows and Android and use WSL to build various linux related releases.run `__02_repack_binary.cmd` it will just zip each binary file, and put it under ./target/  with the zip's name being that target name.there are manual steps below.<hr/>### build:```rustup updatecargo clean#note: visual-studio community with
